# TITUS LAB Stage II — DecisionProblem First Slice

This bounded local crate transforms the exact current `MandateContract` handoff into a deterministic, engagement-bound decision frame. It defines what must be decided, preserves typed facts/assertions/assumptions/hypotheses, records criteria and future evidence requirements, and emits a deterministic planning handoff.

It does not solve the decision. It implements no workstream planning or routing, evidence/research execution, analysis, findings, synthesis, conclusion, recommendation, final decision, delivery, validator, Workbench, frontend, client access, deployment, or Layer 20.

Run the fixed suite with `cargo test --locked`. The suite contains exactly ten tests.
