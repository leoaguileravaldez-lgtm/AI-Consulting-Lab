# Source Lineage and Invalidation

Reusable public knowledge retains exact `04_RESEARCH_EVIDENCE` lineage:

`knowledge version → summarized proposition → claim/evidence relation → evidence version → source version → root source and independence group`.

Layer 08 cannot detach, rewrite, validate, upgrade or replace evidence. A copied summary never inherits validation from another engagement. Material receiving use requires current `04` evidence relations appropriate to the receiving claim.

Independence metadata includes root-source, derivation, common-dataset, common-client, common-method, common-model, prompt/context, template, analyst-team and institutional-dependency groups. One source with ten summaries is one root lineage; one client across five engagements is not five independent confirmations; repeated prompts to one model are not independent replication.

Correction, revocation, expiration, supersession, contradiction, lineage defect, jurisdiction mismatch or applicability failure propagates `04 → 01 canonical evaluation → 08 dependency impact`. Layer 08 may mark dependent knowledge `REVIEW_REQUIRED`, `STALE`, `SUPERSEDED`, `DEPRECATED` or `QUARANTINED` and publish an advisory notice. It cannot change canonical state or blockers.
