# Audit Traceability and Fail-Closed Control

Every Material record and decision event is append-only by design and preserves exact object/version, actor/role/authority, timestamp, client/entity/engagement/jurisdiction boundary, predecessor/successor, reason, source event, dependencies, evidence and professional references, conflicts, SOD result, gate, approval/Human references, outcome, expiry, correlation, and integrity-chain references.

Corrections, revocations, reversals, reclassifications, and supersession create linked new versions. Nothing deletes or overwrites prior risk, dissent, conflict, approval, rejection, exception, waiver, decision, limitation, or audit history.

Deterministic decision lineage is `Decision Record -> typed input collections/counts/manifest hash/snapshot -> exact canonical source objects/versions/hashes and boundaries -> complete Approval Requirement set -> exact Approval Records and condition results -> effective-actor identity graph and mandatory SOD evaluation -> exception/waiver evaluation -> conflict state -> canonical authorities -> Human Principal reference where applicable -> Layer 11 workflow reference`. Each Decision Record and audit event preserves the reconciliation references and outcomes. Missing or mixed lineage blocks the affected gate and decision.

The audit event for a decision records every input category and validated-empty reference, membership/count/hash, input reconciliation, all required/obtained/missing/rejected/expired/revoked/superseded/conditional approvals, approval-chain reconciliation, effective-actor resolution, mandatory SOD results, exception/waiver and conflict evaluations, jurisdiction/compliance/risk/freshness validations, and Human Principal reference. A narrative path, Gate status, Request reference, or partial approval list cannot prove lineage.

## Fail-closed matrix

Any Material defect in authority, provenance, client/entity/engagement identity, jurisdiction, confidentiality, freshness, dependency completeness, unresolved conflict, SOD, approval, Human authority, waiver/exception validity, expiration, or audit yields denial, quarantine, escalation, or revalidation—never readiness, approval, reuse, release, execution, or external action.

`APPROVED` is invalid unless every applicable Decision-specific invariant is current and reconciled. Unknown or missing effective actor, empty configurable SOD rules, truncated approval chain, falsely empty input category, or exception/waiver used as approval fails closed.

Forged/stale/replayed approval; hidden conflict; self/circular approval; vote/confidence/commercial/urgency/timeout/silence/retry authorization; stale assessment; forged jurisdiction; policy/contract conflict; unauthorized/expired/expanded waiver; exception laundering; cross-boundary aggregation; entity confusion; hidden Material defect; Human proxy; or external-action leakage all fail closed regardless of score.
