# Cross-Layer Authority and Interfaces

Layer 13 preserves exact ownership:

- Layer 00: system governance, security, approval categories, permissions policy, and Human Principal controls.
- Layer 01: canonical orchestration, roles/assignments where already owned, audit transitions, and state changes.
- Layer 02: analysis and professional judgment.
- Layer 03: engagement governance.
- Layer 04: evidence authority.
- Layer 05: challenge and dissent.
- Layer 06: risk/QA assurance.
- Layer 07: deliverable readiness, release, publication, and delivery.
- Layer 08: knowledge/reuse.
- Layer 09: client operations.
- Layer 10: client instantiation/isolation.
- Layer 11: execution/workflow governance.
- Layer 12: risk/compliance/decision governance and mandatory SOD baseline.

Layer 13 records identity, access, permission, and authorization semantics only. It cannot appoint canonical roles owned elsewhere, validate evidence, qualify professionals, pass QA, accept risk, override compliance, approve business decisions, release, authorize reuse, change client/engagement state, transition workflow, or execute external actions.

Every cross-layer reference includes owner layer, exact ID/version/hash, scope, purpose, boundary, confidentiality, lifecycle, freshness, expiry/revocation, authority, limitations, and audit. Retrieval, access, administration, or possession does not transfer authority. Canonical drift or unknown ownership denies reliance.
